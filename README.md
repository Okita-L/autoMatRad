# autoMatRad

关键类：`autoProcessor`

## Example

```matlab
projectPath = 'E:\workShop\autoMatRad'; 
addpath(genpath(projectPath));

matRad_rc;
% 禁用GUI
matRad_cfg = MatRad_Config.instance();
matRad_cfg.disableGUI = true; 

%% 创建处理器实例
processor = autoProcessor(projectPath); % 传入路径为 目标文件存放路径 不一定要是projectPath

%% 批量导入Dicom
processor.autoLoadDicomBatch(path_of_Dicom);

%% 批量处理CST
% constraints的创建格式如下
% constraintOfTarget
constraintOfTarget1.className = 'DoseObjectives.matRad_SquaredDeviation';
constraintOfTarget1.parameters = {}; % 否则matlab不知道这是一个元胞数组
constraintOfTarget1.parameters{1} = 30;
constraintOfTarget1.penalty = 800;
% constrainOfOARs
constraint.className = 'DoseObjectives.matRad_SquaredOverdosing';
constraint.parameters={};
constraint.parameters{1} = 54;
constraint.penalty = 300;
% constraintOfParotid
constraintOfParotid1.className = constraint.className;
constraintOfParotid1.parameters={};
constraintOfParotid1.parameters{1} = 28;
constraintOfParotid1.penalty = 300;
% constraintOfBody
constraintOfBody1.className = constraint.className;
constraintOfBody1.parameters = {};
constraintOfBody1.parameters{1} = 55;
constraintOfBody1.penalty = 300;

% ROI的定义格式如下
Targets = {["ctv1", "ctv", "ctv2"], [constraintOfTarget1]};
OARs = {["body", "body1", "body3"],[constraintOfBody1];
    ["brainstem"],[constraint];
    ["opticnerve l"],[constraint];
    ["opticnerve r"],[constraint];
    ["opticchiasm","chiasm"],[constraint];
    ["parotid r"],[constraintOfParotid1];
    ["parotid l"],[constraintOfParotid1];
    };
    
% 开始处理
processor.autoProcessCST();
    
%% 批量生成STF
processor.autoGenerateSTF();

%% 批量生成DIJ和resultGUI
[DIJMatPath,resultGUIPath] = processor.autoGenerateDIJandResultGUI(); % 建议不用 过于占存储

%% 批量生成OAR的csv
processor.autoGetOrgCSV2(); % autoGetOrgCSV效率过低废弃不用

```















## Q&As

### 在导入pln时部分字段值为空

先检查数据是否全部导入——对比文件大小和matlab导入向导显示的大小

若大小一致，可能是matRad环境缺失，命令行执行matRad_rc即可

若大小不一致，pln结构生成出错，检查代码是否完整，matRad_rc版本是否一致。然后重新生成——autoGenerateSTF

## 增加DVH图中显示的OAR

dvh图的生成 `[dvh,qi] = matRad_indicatorWrapper(cst,pln,resultGUI); % figure4 dvh`

修改 matRad_indicatorWrapper 方法中关于ROI的定义

```
expected_targets = {'ctv1','ctv','ctv2'};
expected_oar = {'body', 'brainstem',...
    'opticnerve l','opticnerve r',...
    'opticchiasm','chiasm',...
    'parotid r','parotid l'};  % 保证小写
target_field = [expected_oar,expected_targets];
target_field = lower(target_field);
```

事实上，可以将 matRad_indicatorWrapper 恢复为matRad默认的版本，在调用时传入特定的cst_subset即可



## 增加Slice图中显示的OAR

调用 `matRad_plotSliceWrapper` 时，传入对应参数即可

参数解析：

| 参数名              | 含义                                             | 举例                                                 |
| ------------------- | ------------------------------------------------ | ---------------------------------------------------- |
| **axesHandle**      | 要绘制的坐标轴句柄                               | `gca`                                                |
| **ct**              | CT 数据结构体（`ct.cubeHU`, `ct.resolution` 等） | `ct`                                                 |
| **cst**             | 结构信息表（ROI/OAR/PTV）                        | `cst`                                                |
| **cubeIdx**         | CT 数据索引（通常为 1）                          | `1`                                                  |
| **dose**            | 剂量分布三维矩阵                                 | `resultGUI.RBExD`                                    |
| **plane**           | 切片方向：1=冠状，2=矢状，3=轴向                 | `3`                                                  |
| **slice**           | 第几层切片                                       | `round(pln.propStf.isoCenter(1,3)./ct.resolution.z)` |
| **thresh**          | 剂量下限阈值（低于此值不显示）                   | 通常为空                                             |
| **alpha**           | 剂量叠加透明度                                   | `0.5 ~ 0.8`                                          |
| **contourColorMap** | 结构轮廓颜色表                                   | `colorcube`                                          |
| **doseColorMap**    | 剂量分布颜色表                                   | `jet`、`hot` 等                                      |
| **doseWindow**      | 剂量值范围（最小、最大）                         | `[0, max(resultGUI.RBExD(:))]`                       |
| **doseIsoLevels**   | 等剂量线的剂量百分比（例如 `[0.2, 0.5, 0.8]`）   |                                                      |
| **voiSelection**    | 哪些结构需要绘制                                 | `[true, false, true, ...]`                           |
| **colorBarLabel**   | 色条标签文字                                     | `'Dose (Gy)'`                                        |
| **boolPlotLegend**  | 是否绘制结构图例                                 | `true / false`                                       |

其中 `voiSelection` 的获取如下代码。

**contourColorMap** 可以使用 `colorcube` `jet` 等matlab内置的颜色库，但是我自定义的效果更好

 ATTENTION：slice的选择会影响图片中显示的 Contours

```matlab
%% Plot Slice
        % 创建逻辑数组来筛选 DVH、cst 和 QI
        voiSelection = false(size(cst,1),1);
        for i = 1:size(cst,1)
            if ischar(cst{i,2}) % i行2列 organ_name
                if ismember(lower(cst{i,2}), target_field)
                    voiSelection(i) = true;
                end
            end
        end

        slice = round(pln.propStf.isoCenter(1,3)./ct.resolution.z);
        
        doseWindow = [0 max(resultGUI.RBExD(:))];

        figure,title('original plan');
        myCustomColors = [
            1.0, 0.0, 0.0;  % 1. 亮红色 (Bright Red)
            0.0, 1.0, 0.0;  % 2. 纯绿色 (Pure Green)
            1.0, 1.0, 0.0;  % 3. 亮黄色 (Bright Yellow)
            0.0, 1.0, 1.0;  % 4. 青色 (Cyan)
            1.0, 0.0, 1.0;  % 5. 品红色 (Magenta)
            0.8, 0.5, 0.0;  % 6. 橙色 (Orange)
            1.0, 0.7, 0.7;  % 7. 浅粉色 / 玫瑰色 (Light Pink/Rose)
            1.0, 0.8, 0.0   % 8. 浅橙金色 (Light Orange/Gold)
        ];
        matRad_plotSliceWrapper(gca,ct,cst,1,resultGUI.RBExD,3,78,[],0.75,myCustomColors,[],doseWindow,[],voiSelection,'RBE x Dose [Gy]',true, 'LineWidth', 1); % 'RBE x Dose [Gy]'
        % matRad_plotSliceWrapper(gca,ct,cst,1,resultGUI.RBExD,3,slice,[],0.75,colorcube or jet,[],doseWindow,[]); % figure5 slice
    
```
